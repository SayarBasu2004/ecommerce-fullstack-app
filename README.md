#  Full Stack E-Commerce App

A full-stack e-commerce web application with authentication, cart, checkout, and admin panel.

##  Features

- User authentication (JWT)
- Add to cart & checkout
- Order management
- Admin panel (add/delete products)
- MongoDB database
- Responsive UI

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Zustand

Backend:
- Node.js
- Express
- MongoDB
- JWT Auth

##  Admin Access

To access admin panel:
- Set `isAdmin: true` in user document in MongoDB
